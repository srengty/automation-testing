Private Cloud Storage App

Build a Private Cloud Storage backend with Spring Boot where each user manages their own files & folders, then prove it works with a full test suite that uses every testing method from this lesson — driven by JUnit 5 & Playwright and reported with Allure.

The Brief

What You Are Building

A REST API (optionally with a thin web UI) for a personal cloud drive. Each registered user gets an isolated storage space and can only ever see their own data.

Files & Folders

Create, rename, move, list, download and delete files and folders inside the user's own storage.

Accounts

Register a new user (granted 50 MB), view & edit profile, and delete their own account.

Hard rule: a user must never read, write, or delete another user's files. Enforcing — and testing — this isolation is part of the grade.

Example · Service Test

Equals · Formula · Exception

@SpringBootTest
@Epic("Storage") @Feature("Quota")
class QuotaTest {
  static final long MB = 1_048_576L;
  @Autowired StorageService storage;
  @Autowired UserService users;

  @Test
  void newUserGets50MbAndFormulaHolds() {
    User u = users.register("sok@itc.edu", "Secret123!");
    assertThat(u.getQuotaBytes()).isEqualTo(50 * MB);   // equals

    storage.upload(u, file(10 * MB));
    storage.upload(u, file(15 * MB));
    long free = u.getQuotaBytes() - 25 * MB;          // formula
    assertThat(storage.freeBytes(u)).isEqualTo(free);

    assertThrows(QuotaExceededException.class,           // exception
        () -> storage.upload(u, file(40 * MB)));
  }
}
Three methods, one test class

Example · Playwright API

Regex · Schema · Contains

@Test @Feature("Profile")
void profileEndpointContract() {
  APIResponse res = request.get("/api/me");
  assertThat(res.status()).isEqualTo(200);          // equals

  JsonObject b = JsonParser.parseString(res.text())
                          .getAsJsonObject();
  assertThat(b.has("email")).isTrue();               // schema
  assertThat(b.get("email").getAsString())
      .matches("^[\\w.+-]+@[\\w.-]+$");              // regex

  List<String> folders = names(b.getAsJsonArray("folders"));
  assertThat(folders).contains("Documents");          // contains
}
Tip: seed an authenticated session in a JUnit @BeforeAll / Playwright fixture so each test starts clean and isolated.

Example · Isolation & UI

Predicate · Collection · Visual

// Isolation — predicate over two users
@Test
void usersCannotSeeEachOther() {
  User a = users.register("a@itc.edu", "pw");
  User b = users.register("b@itc.edu", "pw");
  storage.upload(a, named("secret.txt"));

  List<String> bFiles = storage.list(b, "/");
  assertThat(bFiles).doesNotContain("secret.txt")    // collection
                    .isEmpty();
  assertThat(b).matches(                                // predicate
      x -> storage.usedBytes(x) == 0, "b uses nothing");
}
